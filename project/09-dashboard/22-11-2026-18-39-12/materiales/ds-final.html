KPI-03 Margen neto global

Cómo construir la tarjeta en Power BI

Tipo de visual
Tarjeta (la nueva, no la «clásica»): panel Visualizaciones ▸ Tarjeta
Valor grande (DAX)
[Margen neto %] · medida DAX, créala en la tabla Medidas (Nueva medida)DIVIDE ( [Venta bruta] - [Comisión pagada] - [Costo estimado] - [Costo operativo], [Venta bruta] )Sale de las columnas: fPedidos[venta_bruta], fPedidos[comision], fPedidos[costo_estimado], fPedidos[costo_operativo]. Usa antes las medidas: [Venta bruta], [Comisión pagada], [Costo estimado], [Costo operativo] (créalas primero).
Texto de meta (DAX)
[Meta texto KPI-03] · medida DAX, créala en la tabla MedidasMeta texto KPI-03 = VAR meta = CALCULATE ( AVERAGE ( fMetaKpi[meta] ), dKpi[kpi_key] = 3 ) RETURN "Meta: " & IF ( ISBLANK ( meta ), "Pendiente", FORMAT ( meta, "0" ) & " % o más" ) & " · " & [Mes de referencia]Subtítulo de la tarjeta de KPI-03: «Meta: 12 % o más · mes». La meta sale de fMetaKpi[meta], no está escrita a mano.
Chip de estado (DAX)
[Estado KPI-03] · medida DAX, créala en la tabla MedidasEstado KPI-03 = VAR valor = [Margen neto %] VAR meta = CALCULATE ( AVERAGE ( fMetaKpi[meta] ), dKpi[kpi_key] = 3 ) / 100 RETURN IF ( ISBLANK ( meta ), "– Sin meta", IF ( valor >= meta, "✔ Cumple", "✖ No cumple" ) )Texto del chip de KPI-03. Cumple si el valor es mayor o igual a la meta; sin meta muestra «– Sin meta». Se divide entre 100 porque la meta se guarda como 12 y la medida devuelve 0.12.
Color del chip (DAX)
[Color estado KPI-03] · medida DAX, créala en la tabla MedidasColor estado KPI-03 = SWITCH ( LEFT ( [Estado KPI-03], 1 ), "✔", "#0F7B3F", "✖", "#B3261E", "#6B7280" )Color del chip de KPI-03 (verde, rojo o gris). Se usa en Formato condicional ▸ Valor del campo.
Mes de referencia (DAX)
[Mes de referencia] · medida DAX, créala en la tabla MedidasMes de referencia = LOOKUPVALUE ( dCalendario[mes_anio], dCalendario[fecha], MAX ( dCalendario[fecha] ) )Texto del último mes que deja pasar el filtro («oct 26»). Va en el subtítulo de cada tarjeta.
Es la misma para todas las tarjetas: créala una vez.
Cómo armarla (clics)
  1. Arrastra [Margen neto %] al campo Campo de la tarjeta: es el número grande.
  2. Formato de la medida: Herramientas de medida ▸ Formato ▸ Porcentaje, 1 decimal (si no, sale 0.08 en vez de 8.0 %).
  3. Chip: en Visualizaciones ▸ Formato ▸ Elementos visuales ▸ Etiquetas de referencia ▸ enciéndelas ▸ Valor: arrastra [Estado KPI-03]. Si tu versión no tiene Etiquetas de referencia, pon una segunda tarjeta pequeña con esa medida pegada a la primera.
  4. Color del chip: en esa misma etiqueta, color del texto ▸ fx ▸ Formato por: Valor del campo ▸ campo: [Color estado KPI-03].
  5. Subtítulo de meta: en la etiqueta de referencia ▸ Detalle: arrastra [Meta texto KPI-03]; sale «Meta: 12 % o más · oct 26».
  6. Título: General ▸ Título ▸ Texto: el nombre del KPI.
Filtro del visual (clics)
Panel Filtros ▸ arrastra dCalendario[mes_anio] a «Filtros en este objeto visual» ▸ Tipo de filtro: N superior ▸ Mostrar elementos: Superior 1 ▸ Por valor: arrastra dCalendario[anio_mes] (Máximo) ▸ Aplicar filtro. Así la tarjeta siempre muestra el último mes sin escribir «oct 26».

3 KPI del dashboard contra su meta

Cómo construirlo en Power BI

Tipo de visual
Tabla (panel Visualizaciones)
Eje X / filas
Columna kpi de la tabla dKpi (archivo data/limpio/dKpi.csv).
Otras medidas del visual
[Meta del KPI] · medida DAX, créala en la tabla Medidas (Nueva medida)AVERAGE ( fMetaKpi[meta] )Sale de las columnas: fMetaKpi[meta].
Columnas de la tabla (DAX)
No arrastres las 7 medidas: cada una repetiría su valor en las 7 filas. Usa estas 4 (la primera es solo de apoyo y no se arrastra; vienen en la sección «Medidas DAX de las tarjetas y chips»):
[Valor numérico del KPI] · medida DAX, créala en la tabla MedidasValor numérico del KPI = SWITCH ( SELECTEDVALUE ( dKpi[kpi_key] ), 1, [Calidad de datos %], 2, [Margen de contribución %], 3, [Margen neto %], 4, [Merma %], 5, [Error del pronóstico %], 6, [Precio promedio del pollo vivo], 7, CALCULATE ( [KPI con meta %], ALL ( dKpi ) ) )Devuelve el valor del KPI de cada fila. El KPI-07 usa ALL(dKpi) porque cuenta todos los KPI y no solo el de la fila.
[Valor del KPI] · medida DAX, créala en la tabla MedidasValor del KPI = VAR v = [Valor numérico del KPI] RETURN IF ( SELECTEDVALUE ( dKpi[kpi_key] ) = 6, "S/ " & FORMAT ( v, "0.00" ), FORMAT ( v, "0.0 %" ) )El mismo valor, ya como texto con su unidad (% o S/).
[Meta del KPI (texto)] · medida DAX, créala en la tabla MedidasMeta del KPI (texto) = VAR k = SELECTEDVALUE ( dKpi[kpi_key] ) VAR meta = AVERAGE ( fMetaKpi[meta] ) RETURN IF ( ISBLANK ( meta ), "Pendiente", FORMAT ( meta, "0" ) & " % " & IF ( k IN { 4, 5 }, "o menos", "o más" ) )Meta de la fila, con el sentido (o más / o menos). KPI-04 y KPI-05 son «o menos».
[Estado del KPI] · medida DAX, créala en la tabla MedidasEstado del KPI = VAR k = SELECTEDVALUE ( dKpi[kpi_key] ) VAR valor = [Valor numérico del KPI] VAR meta = AVERAGE ( fMetaKpi[meta] ) / 100 RETURN IF ( ISBLANK ( meta ), "– Sin meta", IF ( IF ( k IN { 4, 5 }, valor <= meta, valor >= meta ), "✔ Cumple", "✖ No cumple" ) )Chip de cada fila de la tabla.
El campo dKpi[kpi] va en Columnas; después arrastra, en este orden: [Valor del KPI], [Meta del KPI (texto)], [Estado del KPI]. Para el color del chip: [Estado del KPI] ▸ Formato condicional ▸ Color de fuente ▸ Valor del campo ▸ [Color del estado].
Filtros del visual
dCalendario[mes_anio] = último mes del periodo
Orden, porcentajes y etiquetas (para que salga en su posición)
  1. Ordena dKpi[kpi] por la columna kpi_key: en el panel Datos selecciona la columna ▸ Herramientas de columna ▸ Ordenar por columna ▸ kpi_key. Se hace una vez y vale para todos los visuales.
  2. En el visual, haz clic en el encabezado de la columna kpi para ordenar; con la columna clave KPI-01 a KPI-07 quedan en ese orden.
Archivos CSV de origen
data/limpio/dKpi.csv, data/limpio/fMetaKpi.csv
Valor esperado
7 filas, mes oct 26

Medidas DAX globales

Créalas una sola vez, en este orden, y después úsalas en todas las páginas. Primero crea la tabla que las guarda: Inicio ▸ Especificar datos, con una columna cualquiera, y nómbrala Medidas. Luego, con esa tabla seleccionada, usa Nueva medida para cada una. Cada medida solo depende de las anteriores de la lista. Los nombres deben quedar exactamente como se ven, porque las otras fórmulas los llaman entre corchetes.

1 [Venta bruta]

MED-01 · medida DAX

Suma de la venta bruta de las líneas válidas (las líneas descartadas tienen la venta en 0).

Venta bruta = SUM ( fPedidos[venta_bruta] )Columnas que usa: fPedidos[venta_bruta].

Se usa en: PAG-01 · tarjeta KPI-03; PAG-01 · gráfico 1; PAG-01 · gráfico 3; PAG-02 · tarjeta KPI-02; PAG-02 · gráfico 1; PAG-02 · gráfico 3.

2 [Comisión pagada]

MED-02 · medida DAX

Suma de la comisión que cobran las aplicaciones (0 en salón, para llevar y WhatsApp).

Comisión pagada = SUM ( fPedidos[comision] )Columnas que usa: fPedidos[comision].

Se usa en: PAG-01 · tarjeta KPI-03; PAG-01 · gráfico 1; PAG-01 · gráfico 3; PAG-02 · tarjeta KPI-02; PAG-02 · gráfico 1; PAG-02 · gráfico 2.

3 [Costo estimado]

MED-03 · medida DAX

Suma del costo estimado de cada línea: insumos del producto, con el precio del pollo vivo del día.

Costo estimado = SUM ( fPedidos[costo_estimado] )Columnas que usa: fPedidos[costo_estimado].

Se usa en: PAG-01 · tarjeta KPI-03; PAG-01 · gráfico 1; PAG-01 · gráfico 3; PAG-02 · tarjeta KPI-02; PAG-02 · gráfico 1.

4 [Costo operativo]

MED-04 · medida DAX

Suma del costo operativo del mes (planilla, alquiler, servicios y otros) repartido entre las líneas.

Costo operativo = SUM ( fPedidos[costo_operativo] )Columnas que usa: fPedidos[costo_operativo].

Se usa en: PAG-01 · tarjeta KPI-03; PAG-01 · gráfico 1; PAG-01 · gráfico 3.

5 [Margen neto %]

MED-06 · medida DAX

Lo que queda de cada sol vendido después de la comisión, el costo estimado y el costo operativo.

Margen neto % = DIVIDE ( [Venta bruta] - [Comisión pagada] - [Costo estimado] - [Costo operativo], [Venta bruta] )Columnas que usa: ninguna directa. Necesita antes: [Venta bruta], [Comisión pagada], [Costo estimado], [Costo operativo].

14 [Pronóstico de referencia]

Promedio de lo vendido en las cuatro jornadas anteriores del mismo día de la semana y el mismo turno.

Pronóstico de referencia = VAR fechaActual = MAX ( dCalendario[fecha] ) VAR diaSemana = WEEKDAY ( fechaActual, 2 ) VAR anteriores = TOPN ( 4, FILTER ( ALL ( dCalendario ), dCalendario[fecha] < fechaActual && WEEKDAY ( dCalendario[fecha], 2 ) = diaSemana ), dCalendario[fecha], DESC ) RETURN AVERAGEX ( anteriores, CALCULATE ( [Pollos vendidos] ) )Columnas que usa: dCalendario[fecha]. Texto o color · medida DAX
