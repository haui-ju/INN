# Plantillas del sistema de diseño

Formatos obligatorios para cada entregable del playbook [`../guia.md`](../guia.md). Léelo primero: aquí solo está el formato; el método y las reglas están en el playbook.

## Convenciones

- **Estructura de cada plantilla:** ficha (entregable, entradas, salida) → instrucciones para el agente → formato a copiar → ejemplo → checklist.
- **Marcadores:** `[campo]` se rellena con el valor del proyecto.
- **Ejemplos:** muestran el formato con contenido neutro; no se copian como resultados.
- **Tokens:** se citan por su ruta (`color.claro.acento`, `espacio.4`).
- **Citas:** máximo 1 o 2, solo de las referencias del playbook.
