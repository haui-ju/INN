# Plantillas del brief

Formatos del playbook [`../guia.md`](../guia.md). Léelo primero: aquí solo está el formato.

## Convenciones
- **Estructura de cada plantilla:** ficha (entregable, entradas, salida) → instrucciones para el agente → formato → ejemplo → checklist.
- **Encabezados exactos** (la validación los lee): `## 1. Tema y empresa` a `## 8. Supuestos y riesgos iniciales`, y `### 3.1.`, `### 3.2.`, `### 4.1.` y `### 4.2.`.
