# Plantillas del armado del informe

Formatos de las partes del informe que el armado escribe por sí mismo. El contenido de los capítulos sale de las corridas de las skills `03` a `11`. Léelo junto con [`../guia.md`](../guia.md).

## Convenciones

- **Estructura de cada plantilla:** ficha (entregable, entradas, salida) → instrucciones para el agente → formato → ejemplo → checklist.
- **Fechas:** `DD-MM-AAAA`. **Referencias:** APA 7 (`common/citation-style/APA7.md`).
- **Ejemplos:** usan el proyecto de la Pollería Don Tito de los demás playbooks; no se copian como resultados.
